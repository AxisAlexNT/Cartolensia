# AI assistance

Cartolensia is developed with AI-assistance.

Large language models may be used for brainstorming, planning, refactoring, test generation, documentation, and implementation support. 

Project policy:

- Do not copy source code from third-party repositories or webpages.
- Use third-party code only through explicit dependencies and compatible licenses.
- Prefer dependencies with MIT, BSD, Apache-2.0, ISC, MPL-2.0, or similarly compatible licenses.
- Generated code must be based on project requirements, not copied from external source files.
- Significant AI-assisted changes should still pass normal review, tests, and license checks.
