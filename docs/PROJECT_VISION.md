# Product vision

Cartolensia is a self-hosted multimedia archive for people whose photos, videos, and tracks are tied to movement, places, vehicles, routes, and technical observations.

Unlike family-album-first tools, Cartolensia is designed for large archives where the user may not remember the year, device, or folder, but may remember a place, route, vehicle model, landscape, artifact, or approximate trip.

The product should make it possible to:

- browse media through maps and time;
- find photos and videos near GPS tracks;
- infer locations for media without embedded geotags;
- search by text, visual similarity, metadata, and AI-derived tags;
- classify places, vehicles, and other entities;
- manage huge heterogeneous media collections without modifying originals;
- stream and transcode media safely;
- work offline using cached and bundled resources.
