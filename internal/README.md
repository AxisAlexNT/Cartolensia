# Internal Packages

Planned MVP packages:

- `app`: bootstrap and dependency wiring.
- `config`: YAML/env config loading and validation.
- `database`: PostgreSQL connection, migrations, and capability checks.
- `storage`: storage URL parsing, registry, and adapters.
- `plugins`: plugin manifest loading and dependency sorting.
- `jobs`: PostgreSQL-backed persistent jobs.
- `discovery`: filesystem scan and metadata indexing.
- `media`: MIME, hashing, metadata, streaming, and preview helpers.
- `server`: REST API and static WebUI serving.
